# CSD 340 Web Development with HTML and CSS

## Project Overview

This project is a bioSite about Natasha Androsky. The website provides information about her background, interests, hobbies, and family. It uses a combination of written content and photographs to introduce different aspects of her life.

## Website Pages

- **Home:** Introduces Natasha and provides an overview of the website.
- **About:** Provides more information about Natasha's background and personal life.
- **Hobbies:** Covers some of Natasha's hobbies and interests.
- **Family:** Introduces Natasha's family members through individual profiles and photographs.

## Technologies Used
- HTML5 for creating pages and content
- CSS3 for styling and organization
- CSS Grid for arranging text and images
- Google Fonts for typography
- Git and GitHub for version control and hosting

## Deployment
The site is hosted through GitHub Pages and can be viewed [here](https://brandrosky.github.io/bioSite/).
